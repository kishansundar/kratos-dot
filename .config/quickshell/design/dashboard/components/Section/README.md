# Section

The one heading style of the dashboard: a `caps` label in `text` on a 1px ink (`text`) rule, the group's scale or count at the right in `mono` `textMuted`, `hitTarget` tall with the label `s1` above the rule.

**Consumer provides:** title, metadata (scale, window, count).

- Used for every group: Compute, Memory, Heat, Network, Processes, Storage, Controls. No `h2` section titles, no heading rulers inside the panel; the host name is the only `h2`.
- Metadata is factual and short: the scale ("20–100 °C · warn 80 · critical 90"), the window, a count.
