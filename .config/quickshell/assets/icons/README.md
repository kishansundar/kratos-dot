# Shell icons

The symbols are Material Symbols Sharp (Google, Apache-2.0), a variable font installed by
`~/nixos/modules/fonts.nix` (`pkgs.material-symbols`) and drawn by `components/Icon.qml` by name. Nothing for them
is kept here.

`claude.svg`: Claude's own mark, so Claude Code is shown by its mark as tray apps are shown by theirs. Path data from
Simple Icons (https://simpleicons.org, CC0 1.0), taken unmodified from
https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/claude.svg. The mark itself is a trademark
of Anthropic. Which symbol means what: Theme.qml, `icons`.
